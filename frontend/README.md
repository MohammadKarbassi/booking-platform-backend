# دور ایران: فرانت‌اند سامانهٔ رزرو اقامتگاه

«دور ایران بگردیم» (بازی با «دورت بگردم»). اقامتگاه‌هایی که نقطهٔ شروع کشف جاهای تازهٔ ایران‌اند.

**پشتهٔ فنی:** Next.js 16 (App Router)، Tailwind CSS 4، shadcn/ui (Radix، RTL)، TanStack Query، react-hook-form + zod، Leaflet. تمام صفحه‌ها فارسی و راست‌به‌چپ، اعداد فارسی، تاریخ‌ها شمسی، قیمت‌ها به تومان.

## اجرا
بک‌اند و دیتابیس باید روشن باشند (راهنما: `../backend/README.md`). سپس:

</div>

```bash
npm install
```

```bash
cp .env.example .env.local
```

```bash
npm run dev
```

<div dir="rtl">

سایت روی http://localhost:3000 بالا می‌آید. درخواست‌های `/api/*` را خود Next به آدرس `BACKEND_URL` (پیش‌فرض `http://localhost:8000`) می‌فرستد، پس بک‌اند CORS لازم ندارد.

**حساب‌های نمونه** (کد ورود در حالت توسعه روی صفحه نشان داده می‌شود، چون پیامک شبیه‌سازی شده):
- مسافر: `09125555555` (سارا)
- مدیر: `09120000000`

برای دادهٔ تمیز قبل از دمو: `cd ../backend && .venv/bin/python -m app.seed --reset`

## صفحه‌ها
| مسیر | کار |
|---|---|
| `/` | «دور ایران بگردیم»، جست‌وجو، قطب‌نمای کشف یک اقامتگاه، کارت‌پستال‌ها، نقشهٔ ایران |
| `/stays` | جست‌وجو و فیلتر (شهر، تاریخ آزاد، نفرات، نوع، امکانات، قیمت، نام)، مرتب‌سازی، صفحه‌بندی، نمای نقشه. همهٔ وضعیت در URL است |
| `/stays/[id]` | گالری، امکانات، میزبان، قوانین، **قطب‌نمای جاذبه‌های اطراف** و نقشه، تقویم شمسی با قیمت هر روز، نظرها، کارت رزرو با قیمت شب‌به‌شب و صف انتظار |
| `/login` | ورود با کد یک‌بارمصرف (شماره با ارقام فارسی هم پذیرفته می‌شود) |
| `/checkout/[id]` | بلیت رزرو، شمارش معکوس ۱۵ دقیقه، پرداخت یا لغو |
| `/gateway` | درگاه پرداخت **آزمایشی** (بدون فرم کارت؛ فقط نتیجه را انتخاب می‌کنی) |
| `/trips` | «سفرنامهٔ من»: گذرنامه با مهر شهرهای دیده‌شده، رزروها، پرداخت، لغو، رسید، نوشتن نظر |
| `/waitlist`، `/favorites`، `/profile` | صف انتظار، نشان‌شده‌ها، پروفایل |
| `/admin/*` | پنل مدیریت: اقامتگاه‌ها (ساخت، ویرایش، وضعیت)، تقویم و قیمت روزانه، قانون‌های قیمت، رزروها، تأیید نظرها، میزبان‌ها، تعطیلات، جاذبه‌ها |

## ایدهٔ طراحی
- **کارت‌پستال و مهر پست:** هر اقامتگاه یک کارت‌پستال با تمبر و مهر شهر است؛ هر سفر قطعی یک مهر در گذرنامهٔ مسافر.
- **قطب‌نمای کشف:** جاذبه‌های اطراف (`/accommodations/{id}/nearby`) با جهت جغرافیایی واقعی و فاصلهٔ لگاریتمی، همراه زمان پیاده یا با ماشین.
- **صدای هر کارت‌پستال:** با روشن کردن «صدا» در سربرگ، روی هر کارت صدای همان‌جا پخش می‌شود (موج، جنگل، کوهستان، باد کویر، فوارهٔ باغ ایرانی). صداها با Web Audio API ساخته می‌شوند؛ فایل صوتی ندارد.
- رنگ‌ها: لاجورد، زعفران، انار، فیروزه روی کاغذ نقشه. فونت‌ها: Lalezar برای تیترها، Vazirmatn برای متن.
- الهام: سایت Netflix «Voyage en France» (برندهٔ Awwwards) با ایدهٔ سفرنامه و کارت‌پستال.

عکس‌ها از ویکی‌مدیا کامنز با مجوز آزاد (فهرست در `public/stays/CREDITS.md`).
